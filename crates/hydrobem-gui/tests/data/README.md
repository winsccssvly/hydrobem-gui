# Test data of the GUI

The models and meshes the tests of `hydrobem-gui` read, copies of those of
`crates/gui-core/tests/data` (its README lists them) that these tests use, and
`two_truncated_cylinders.gdf` (a second mesh file to drop). Written by `python
scripts/make_testdata.py` and `cargo xtask testdata`; do not edit them by hand.
